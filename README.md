## 一、禁止事项（最高优先级）

以下行为一律禁止：

1. 政治、宗教、极端主义用途
2. R18、违法、公序良俗或良知违背内容
3. 模型本体或素材再配布
4. 低质量修改或提取素体伪装自制模型(是不是自制的看你布线就够了)
5. 任何赞助、订阅或变相盈利（含
   Patreon 等平台、视频制作收益除外）
6. 上传至
   VRChat
   或任何公开Avatar平台

> 在我眼里 三次元人类套用二次元皮的时候就已经是在侮辱原有角色形象了 重点是我反感

8. 违反原IP官方规范的使用

## 二、商业使用

仅允许：

**独立开发团队商业使用**

必须同时满足：

* 非公司、非工作室、非企业主体
* 无发行商或投资方
* 非外包项目
* 非企业化运营

允许：

* 独立游戏开发与销售
* 正常平台收入

以下全部视为企业使用：

* 公司或工作室主体
* 有发行商或投资
* 商业外包或企业项目

> 只要属于企业
> **永久禁止一切商业使用**
> **不存在授权、购买、例外或任何协商可能**

## 四、联网与MOD(视频制作不属于此类)

**联网内容全面禁止**

包括但不限于：

* 网络游戏
* MMO
* 在线合作
* 云端加载
* 玩家可见模型

无论是否盈利
只要联网即禁止

**MOD仅限单机**

允许：

* 单机MOD
* 本地离线MOD
* 仅本地可见

禁止：

* 联机MOD
* 可被他人看到
* 通过MOD盈利或赞助

## 五、允许事项

在遵守全部限制前提下允许：

* 个人与独立项目使用
* 深度改造（禁止模型本体再配布）
* 单机项目
* 视频制作和开启创作者收益
* 3D生成式AI训练

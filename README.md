# 死梦模型协议 2.0

适用于死夢めぐり发布的全部模型及其衍生内容。使用即视为同意。

## 禁止

- 禁止再配布模型本体（含改模）
  「再配布」指以模型文件形式提供给他人；封装进游戏、视频等成品不算
- 禁止上传模之屋、VRChat 等模型配布或共享平台
- 禁止联机使用或让他人看见（联机 MOD、在线合作、云端加载一律禁止）
- 禁止企业使用：公司、工作室、有发行商或投资、外包，一律永久禁止，不接受洽谈
- 禁止赞助、订阅等变相盈利（视频收益、你自己独立游戏的销售与众筹除外）
- 禁止 R18、政治宗教、违法或违背公序良俗
- 禁止提取素体伪装自制
- 禁止用作真人的虚拟形象（VTuber、直播与社交平台的个人形象等）
  三次元人类套二次元皮在我眼里就是在侮辱原有角色形象，重点是我反感
- 禁止违反原 IP 官方规范

## 允许

- 个人使用、单机、本地 MOD（仅自己可见）
- 自由改造，改完自用（仍不得配布本体）
- 视频制作并开创作者收益
- 独立开发者商用（非公司 / 无发行商投资 / 非外包）
- 3D 生成式 AI 训练（产出不得包含可还原的模型本体，也不得据此声称自制）
- 单独配布你自己原创的衣服 / 头发 / 配件（不含我的模型本体）

以上允许仅适用于我的一次创作模型；二创模型以原版权方条款为准。

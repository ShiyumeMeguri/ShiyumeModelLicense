## 死梦模型协议 1.0

适用于作者(死夢めぐり)发布的全部一次创作、二次创作模型及其衍生内容。
获取、持有或使用模型即视为同意本协议全部内容。

**最高优先级版本（以 GitHub 最新为准）：**
[https://github.com/ShiyumeMeguri/ShiyumeModelLicense/blob/main/README.md](https://github.com/ShiyumeMeguri/ShiyumeModelLicense/blob/main/README.md)
该仓库内容优先于任何本地下载或转载版本

# ⛔ 一、禁止事项（最高优先级）

| 类别       | 行为                     | 状态   |
| -------- | ---------------------- | ---- |
| 🏛️ 政治宗教 | 政治、宗教、极端主义用途           | ❌ 禁止 |
| 🔞 合规与伦理 | R18、违法、公序良俗或良知违背内容     | ❌ 禁止 |
| 📦 再配布   | 模型本体或素材再配布             | ❌ 禁止 |
| 🧬 伪原创   | 低质量修改或提取素体伪装自制模型       | ❌ 禁止 |
| 💰 盈利    | 任何赞助、订阅或变相盈利（视频制作收益除外） | ❌ 禁止 |
| 🌐 公共平台  | 上传至模之屋、VRChat或任何公开平台   | ❌ 禁止 |
| 🎭 角色形象  | 在我眼里 三次元人类套用二次元皮的时候就已经是在侮辱原有角色形象了 重点是我反感       | ❌ 禁止 |
| 📜 原IP规范 | 违反原IP官方规范使用            | ❌ 禁止 |

> 只要触及以上任一项 → **一律禁止**

# 💼 二、商业使用规则

## 🟢 仅允许：独立开发团队商业使用（必须全部满足）

| 条件   | 要求           | 状态      |
| ---- | ------------ | ------- |
| 主体性质 | 非公司、非工作室、非企业 | 🟢 必须满足 |
| 投资发行 | 无发行商、无投资方    | 🟢 必须满足 |
| 项目性质 | 非外包项目        | 🟢 必须满足 |
| 运营结构 | 非企业化运营       | 🟢 必须满足 |

### 🟢 在满足以上全部条件下允许

| 行为        | 状态   |
| --------- | ---- |
| 独立游戏开发与销售 | ✅ 允许 |
| 正常视频平台收入    | ✅ 允许 |
